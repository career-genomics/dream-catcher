## Quick Start (Or How to Catch Dreams in 3 Steps) 🚀

### Prerequisites
- Docker (because containers aren't just for shipping anymore)
- A sense of humor (mandatory)
- Career dreams (recommended but not required)

### Launch the Dream Catching Machine

1. **Clone this beauty:**
```bash
git clone https://github.com/yourusername/dream-catcher.git
cd dream-catcher
```

2. **Wake up the containers:**
```bash
docker-compose up -d
```

3. **Visit the magic portal:**
   - Frontend: `http://localhost:3000` (where dreams come true)
   - Backend API: `http://localhost:8000` (where the magic happens)
   - Health Check: `http://localhost:8000/health` (to make sure it's still alive)
